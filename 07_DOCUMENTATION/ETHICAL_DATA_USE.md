# Ethical data use

This package is designed around public-source news data. The repository does not publish raw social-media content and intentionally excludes social-media analysis from the current research release.

Do not commit API tokens, cookies, passwords, session files, private datasets, or personal information. Respect source-site terms, copyright, rate limits, and applicable law when collecting news.

Analytical outputs should be interpreted as aggregate governance-risk signals. They should not be used to infer individual wrongdoing or attribute misconduct to BPKH without independent verification.
