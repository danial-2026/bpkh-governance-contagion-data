# Data dictionary

## Aggregated analytical datasets
- `monthly_ews.csv`: monthly NCI, anomaly score, EWS/GCR scores and levels.
- `risk_dimensions.csv`: dimension-level document counts, prevalence, and mean semantic score.
- `network_nodes.csv`: node-level centrality and NCI components.
- `network_edges.csv`: risk-dimension co-occurrence and association metrics.
- `contagion_events.csv`: event size, document contagion score, and component scores.
- `lag_analysis.csv`: external-crisis lead/lag relationships at 0–3 months.

## Release metadata
Each release contains a manifest with dataset version, observation period, status, and release path.

## Privacy
Raw article text and raw social-media data are not part of the public release.
