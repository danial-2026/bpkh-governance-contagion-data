# Governance Intelligence Architecture

```text
DATA LAYER
News + official/oversight sources supplied by the user
        ↓
INTELLIGENCE LAYER
Semantic mapping → Event analysis → Network → Temporal → Anomaly
        ↓
RISK LAYER
External Crisis + BPKH Exposure + Public Trust + GCI + NCI
        ↓
EARLY-WARNING LAYER
AI-based EWS + Integrated Governance Contagion Risk
        ↓
DECISION LAYER
Verification → Clarification → Management Review → Mitigation
```

The architecture separates the analytical/data lifecycle from the dashboard/frontend lifecycle. The PWA consumes versioned datasets and can update its data layer without redeploying the frontend.
