# BPKH Governance Contagion Research & Intelligence Toolkit

This repository packages the research data layer, reproducibility materials, analytical scripts, results, and the BPKH Governance Contagion Early-Warning PWA prototype.

## Scope
The analytical corpus in this release uses **NEWS MEDIA ONLY**. Social-media data are intentionally excluded from the research pipeline and from the public analytical outputs.

Observation period: **1 January 2024 – 3 September 2026**.

The study examines governance contagion as an ecosystem-level reputational and institutional exposure mechanism. It does not attribute misconduct to BPKH, estimate corruption probability, or establish causal transmission.

## Repository map
- `01_RESEARCH/` — research design, methodology, references.
- `02_DATA/` — versioned aggregated analytical data and release manifests.
- `03_SCRIPTS/` — sanitized, news-only analytical scripts.
- `04_RESULTS/` — selected tables and figures used for the manuscript.
- `05_PWA/` — frozen institutional prototype and data-layer architecture.
- `06_GOVERNANCE_INTELLIGENCE_TOOLKIT/` — risk taxonomy, EWS interpretation, response protocol, and architecture.
- `07_DOCUMENTATION/` — reproducibility, limitations, ethical data use, and changelog.

## Privacy and credentials
No personal absolute paths, API keys, tokens, passwords, or private credentials are intentionally included. BPKH/user-specific inputs must be supplied locally.

## Research snapshot
The frozen analytical release is `2026.09.03`. The `2026.09.24-DEMO` release is synthetic and exists only to demonstrate remote dataset updating in the PWA. It must not be interpreted as research output.

## PWA
The PWA is an analytical decision-support prototype. It is not an official BPKH risk rating, corruption detector, probability-of-misconduct model, or causal risk-transmission model.
